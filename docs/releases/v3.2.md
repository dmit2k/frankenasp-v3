# FrankenASP 3.2

Native ARM32 FrankenASP V3 installer, launcher, and Bionic factory ASP helper for:
- **Echo Show 8 (2nd generation)** — `athena`
- **Echo Spot (1st generation, 2017)** — `rook`

## Code changes since 3.1

- **Isolated OTA lookup:** the installer no longer searches TECHO5's shared `/data/techo5-linux` directory for downloaded firmware by default. It looks inside its own verified cache at `/data/techo5-linux/asp-installer-cache/ota-images/` instead.
- **New `--ota-search-dir DIR` option:** explicitly select an alternate directory for searching previously saved local OTA candidates. The older `--tmp-dir DIR` option remains as a deprecated compatibility alias; neither option changes where OTA downloads are written.
- **Safe local OTA disk preflight:** disk-space checking for local OTA extraction now uses the existing private cache root and no longer assumes `ota-images/` is already present.
- **Versioned archive filenames:** release packages now include the full version in their filenames (`frankenasp-v3.2-athena-arm32.tar.gz` and `frankenasp-v3.2-rook-arm32.tar.gz`). The GitHub Release workflow verifies and publishes those filenames.

**DSP functionality:** no changes to the platform-specific factory DSP launchers/helpers since 3.1. These binaries are rebuilt into the 3.2 release packages alongside the updated installer.

## Installation

The archives contain **FrankenASP-owned binaries and configuration only**. No Amazon firmware, proprietary libraries, or calibration data is distributed. Supply your own compatible full OTA or a previously verified local factory cache.

See [ASP-INSTALL.md](https://github.com/dmit2k/frankenasp-v3/blob/v3.2/docs/ASP-INSTALL.md) for requirements, deployment paths, maintenance commands, and the cache policy. External ASP integration on the TECHO5 host remains a separate component.
