# FrankenASP 3.3

**The only recommended and supported stable FrankenASP V3 release.** Earlier releases remain available for historical reference but are superseded by 3.3.

This release includes three independently downloadable packages:

- **Echo Show 8 (2nd generation, `athena`):** `frankenasp-v3.3-athena-arm32.tar.gz` — on-device installer and platform-specific runtime components.
- **Echo Spot (1st generation, `rook`):** `frankenasp-v3.3-rook-arm32.tar.gz` — on-device installer and platform-specific runtime components.
- **Linux x86_64 desktop:** `asp-extractor-v3.3-linux-amd64.tar.gz` — factory-file extraction, verified local firmware cache management and secure delivery to Echo devices.

## What's new

- **Added `asp-extractor`:** prepare factory ASP files from compatible full OTA images or supported TECHO5 backups on Linux, maintain a reusable local firmware library, and transfer the selected cache and installer package to an Echo.
- **Updated factory firmware cache format:** helper-independent, SHA-256-verified factory file sets, content-based deduplication across sources, explicit variants when factory contents genuinely differ, and consistent desktop/device cache compatibility.
- **Many functional improvements, bug fixes, and usability refinements** throughout `asp-installer` and `asp-extractor`, including OTA retention rules, safer cache handling, deployment checks, command output, and documentation.

The desktop extraction workflow shifts the resource-intensive firmware processing to a PC. **Desktop delivery does not install or activate External ASP**: run `asp-installer` on the Echo afterward. Direct on-device installation from a full OTA remains available.

The packages contain **no Amazon proprietary firmware, DSP binaries or calibration data**; factory files must come from a compatible owner-provided source. Only Athena and Rook have been tested and are supported.
