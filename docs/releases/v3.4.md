# FrankenASP 3.4

**Current stable FrankenASP V3 release**, superseding 3.3.

## What's new

- **Echo Spot (1st generation, `rook`):** Reworked the way raw microphone and playback-reference PCM is passed into the factory audio processor. Compared with 3.3, the new approach aims to reproduce the original factory processing path more closely, with less intermediate audio handling.
- Updated Rook validation and regression tests to cover the revised audio path.

**Testing status:** The new Rook implementation has passed software and factory-runtime tests and has been exercised on a physical Echo Spot. **Full acoustic testing is not yet complete, and 100% equivalence to Amazon's original processing has not been confirmed.** Voice recognition with external background music remains under evaluation.

The Athena implementation and the desktop/on-device extraction and installation tools have no functional changes in this release.

- **Echo Show 8 (2nd generation, `athena`):** `frankenasp-v3.4-athena-arm32.tar.gz`
