# FrankenASP 3.6

FrankenASP 3.6 is the new stable release, with bug fixes, reliability improvements, and a substantial internal refactor and code reorganization.

## Highlights

- **Shared, platform-agnostic tooling:** The desktop `asp-extractor` and on-device `asp-installer` now use a common Go module and shared factory-source extraction, ELF dependency handling, Cache V2 verification, and release validation. Platform-specific native launcher/child implementations and release requirements remain separate.
- **Universal source and release workflows:** The tools work with supported full OTA and backup formats across Echo codenames and firmware builds, without hard-coded platform restrictions in the generic extraction and packaging paths. The self-describing release format supports additional platform-specific implementations without changing the common tooling.
- **Platform-owned channel mapping:** Release packaging and installation can carry platform-specific `channel-map` resources. Athena's native DSP helper uses its existing map to reorder the four captured microphone slots and two playback-reference slots independently, enabling controlled routing experiments without changing TECHO5 capture. Other platforms require native helper support to interpret a supplied map; the current Rook helper does not consume one.
- **Improved usability and diagnostics:** Relative cache paths are accepted by the installer and extractor. Their cache listings/status report a shared informational fingerprint of extracted ASP libraries, without changing full cache verification or deduplication.
- **Additional fixes and regression coverage:** Improvements to factory extraction, validation, installer lifecycle handling, and release packaging.

## TECHO5 helper support and firmware compatibility

**Native TECHO5 External ASP helper support is currently provided for two devices:** Echo Show 8 (2nd generation, Athena) and Echo Spot (1st generation, Rook). The common installer, extractor, and packager are designed to operate with other Echo platforms and compatible firmware sources; this does **not** imply that a native DSP helper or launcher is available, or that runtime behavior has been verified, on those devices.

The supported firmware builds and testing scope are maintained in the [Athena](../../platforms/athena/README.md) and [Rook](../../platforms/rook/README.md) platform guides. Additional verified factory cache inventories must not be interpreted as hardware compatibility certification.

FrankenASP remains **v3**. `ASP1-ASSETS-V4` is an internal release manifest format; the factory cache remains Cache V2.

Release packages contain no Amazon firmware, proprietary factory libraries, OTA images, private calibration data, or extracted factory caches.
